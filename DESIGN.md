# WhisperHub PoE 2 Theme

This design system defines the visual language of WhisperHub overlay. It utilizes a dark, atmospheric RPG palette inspired by Path of Exile 2.

## Design Philosophy

- **High-Contrast Overlay Utility:** Streamers and gamers run this over their game client. Contrast must be high, backdrop should block minimal screen details, and key actions (Invite, Dismiss) must be prominent.
- **Skeuomorphic Touch with Modern Glass:** While utilizing modern CSS attributes like `backdrop-blur` and smooth border transitions, colors draw from traditional heavy leather, metals, and embers of PoE.
- **Micro-Animations:** Pulsing status dot and soft hover transitions on action buttons to make the overlay feel responsive.
